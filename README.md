# Age Calculator App 📱

A simple and intuitive Android application built as part of Task 9 in the **Android Development Track**[cite: 1]. This app allows users to select their Date of Birth using a native `DatePicker` widget and automatically calculates their exact current age[cite: 1].

---

## ✨ Features
* **Interactive DatePicker:** Select birth date seamlessly using an Android date selection widget[cite: 1].
* **Real-time Age Calculation:** Computes the user's exact age in years based on the current system date[cite: 1].
* **Clean & Responsive UI:** Built using `LinearLayout` for structured element alignment and readable layout[cite: 1].
* **Input Validation:** Prevents invalid date selections and edge-case calculation errors.

---

## 🛠️ Tech Stack & Tools
* **Language:** Kotlin[cite: 1]
* **UI Layout:** XML[cite: 1]
* **IDE:** Android Studio[cite: 1]
* **Core Components:** `DatePicker`, `Button`, `TextView`, `LinearLayout`[cite: 1]

---

## 📸 How It Works
1. Launch the app and view the date selector[cite: 1].
2. Choose your Date of Birth[cite: 1].
3. Click on the **Calculate Age** button[cite: 1].
4. View your exact age displayed instantly on the screen[cite: 1].
